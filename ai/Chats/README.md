# 产品对话归档

这里保存对产品方向有长期价值的外部 AI 对话的“决策摘要”，不是逐字备份，也不保存凭据、账号、API key、隐藏提示词或完整内部推理。

## 命名

YYYY-MM-DD_<平台>_<主题>.md

例如：

2026-08-09_Trae_动态人设回归测试.md

## 一份归档应包含

- 原始分享链接与日期。
- 为什么值得留存。
- 用户明确作出的产品决定。
- 由此产生的代码/文档位置。
- 后续 AI 接手时还要注意的风险或待验证项。

原始链接可能失效；归档摘要才是仓库内可长期阅读的上下文。若对话需要逐字保存，先人工脱敏后再另存附件，不要把敏感内容直接提交到仓库。
