## 3. 真实场景模型

不要先写“AI 应该回答什么”的剧本。为每个场景保存：

- 初始主诉/任务。
- 用户实际可提供的事实，以及这些事实什么时候暴露。
- 用户能力、权限、设备/账号状态。
- 操作或系统返回后的真实结果。
- 正确结果、关键区分证据、停止条件。
- 图片/附件/外部系统事件，以及确定性的触发规则。

## 4. 结果状态

沿用 PASS / FAIL / ERROR / REVIEW 四种状态。具体含义可扩充，但 ERROR 和 REVIEW 永远不得被汇总成通过。
