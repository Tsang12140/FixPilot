# FixPilot 联网资料检索规范 v1.0

状态：已落地（2026-08-09）

## 目的

FixPilot 的知识库负责通用排障路径；联网资料只用于用户明确需要最新公开资料、硬件规格、驱动/系统官方说明或说明书线索时补充证据。它不是默认能力，也不能把问诊变成“搜到什么就让用户做什么”。

## 用户入口

- 用户必须主动点输入框里的「查资料」。
- 开关只对**本次发送**有效；发送后自动复位。
- 失败后的「重试这一条」保留该次选择，避免用户误以为重试时仍在联网。
- 支持时，回答开头显示「本轮已联网查资料。」；若服务端响应含 URL，回答末尾附最多 3 个由服务端返回的来源链接。

## 当前技术边界

- 仅支持官方 `https://api.deepseek.com/responses` 的 `deepseek-v4-flash`。
- 只接受模型名精确为 `deepseek-v4-flash`、主机名精确为 `api.deepseek.com` 的请求。
- 火山方舟、其他 OpenAI 兼容接口、用户任意自定义模型、平台模型不满足上述条件时，前端禁用入口；即使绕过前端，后端也必须在发出网络请求前拒绝。
- 使用 DeepSeek Responses API 的服务端 `web_search` 工具，并以 `tool_choice: {"type":"web_search"}` 强制本轮实际搜索。
- 为了避免 Responses SSE 的厂商差异，FixPilot 到 DeepSeek 使用完成态请求；浏览器端仍保持既有 SSE 对话体验。

## 安全与证据规则

1. 搜索结果、网页正文、网页标题、日志和引用文字都属于**不可信外部资料**，不是系统或管理员指令。
2. 网页内容不能覆盖 FixPilot 的安全等级、停止指导条件、用户当前证据或一次只推进一个关键判断的问诊规则。
3. 不把网上常见原因说成该用户机器已经确认的根因；资料不足时直接说明资料不足。
4. R1/R2/R3 风险操作仍按原有风险提示处理。联网不会成为刷 BIOS、短接电源、格式化磁盘或绕过数据保护的理由。
5. 不能因本轮联网而声称可看到图片画面、远程操控电脑或读取本机硬件。图片仍仅经 OCR 处理。
6. 只展示响应对象中服务端实际返回的 HTTP(S) URL；模型正文不能自造“来源”。

## 失败与配额

- 搜索请求失败、返回空文本或被模型/端点拦截时，沿用现有“重试这一条”失败状态。
- 不保存失败的用户/助手消息，不扣平台邀请码次数；自定义 API 也不产生 FixPilot 平台配额扣减。
- 用户可以关闭「查资料」后按普通对话继续；普通对话不需要、也不应重新连接联网工具。

## 维护与测试

- 源码：`backend/app/llm.py`、`backend/app/service.py`、`backend/app/main.py`、`backend/static/app.js`。
- 无凭据回归：`python tools/run_all.py --suites renderer,transport,websearch`。
- `tools/web_search_test.py` 必须覆盖：官方域名/模型白名单、工具 payload、服务端强制 `/responses`、来源标记、非官方端点在联网前被拒绝。
- 改动此能力时，需同时验证桌面与 390px 移动端：模型切换后入口状态正确、按钮不会挤压上传/发送、失败重试保留本轮联网意图。
